# Формулы веб-интерфейса

В этом справочнике перечислены значения, которые VoltFlow рассчитывает и показывает в
веб-интерфейсе. Документ организован по страницам, чтобы отображаемое число можно было
сопоставить с его формулой, смыслом и реализацией-владельцем.

Каноническое описание поведения предметных областей находится в документах [сессий зарядки](CHARGING_SESSIONS.md),
[поездок](TRIPS.md) и [телеметрии](../supabase/TELEMETRY.md). Если этот справочник
расходится с одним из них, конфликт нужно устранить, а не считать этот краткий справочник
новым источником истины.

## Область, обозначения и терминология

Включены пользовательские расчёты продукта, выполняемые в браузере, на сервере Next.js
или в read model базы данных. Сырая телеметрия, отображаемая без изменений, отмечена там,
где это полезно, но формулой не считается. Исключены геометрия SVG/карты, координаты
графиков, пагинация, пороги только для валидации, размеры изображений и обычное
форматирование чисел/дат.

### Обозначения формул

| Символ или термин | Значение | Единица или диапазон |
| --- | --- | --- |
| `C` | Настроенная полезная ёмкость батареи при полном заряде | кВт·ч |
| `SOC` | Состояние заряда батареи: насколько она заполнена | 0–100% |
| `start SOC` | Процент батареи в начале зарядки или поездки | 0–100% |
| `current SOC` | Последний выбранный процент батареи: преимущественно live, иначе телеметрия или оценка | 0–100% |
| `target SOC` | Процент батареи, при котором пользователь хочет остановить зарядку | 0–100% |
| `SOC gain` | `current SOC − start SOC`; добавленные процентные пункты при зарядке | Процентные пункты |
| `SOC drop` | `start SOC − end SOC`; процентные пункты, израсходованные при движении | Процентные пункты |
| `SOH` | Состояние батареи относительно номинальной ёмкости | Процент |
| `η` | Эффективность зарядки конкретного тарифа: доля энергии сети, сохранённая в батарее | Процент |
| `P` | Мощность зарядки: скорость передачи энергии | кВт |
| `live P` | Свежая мощность зарядки со стороны сети, сообщённая автомобилем | кВт |
| `P_grid` | Мощность со стороны сети для отображения или ETA по сетевой энергии | кВт |
| `P_batt` | Эквивалентная мощность на стороне батареи для проекции SOC: `P_grid × η/100` | кВт |
| `p` | Цена одного сетевого кВт·ч электроэнергии | Валюта/кВт·ч |
| `d` | Пройденное расстояние | км |
| `battery energy` | Энергия, сохранённая в ячейках батареи или израсходованная из них | кВт·ч |
| `grid energy` | Энергия, взятая из сети или у оператора зарядки; включает потери и вспомогательное потребление | кВт·ч |
| `remaining battery energy` | Энергия на стороне батареи, нужная для перехода от текущего SOC к целевому | кВт·ч |
| `remaining grid energy` | Ожидаемая энергия из сети от текущего SOC до целевого с учётом потерь | кВт·ч |
| `charged grid energy` | Оценка энергии из сети, уже полученной сессией зарядки | кВт·ч |
| `usable energy` | Доступная для движения энергия с учётом SOC и, в AI-модели запаса хода, SOH | кВт·ч |
| `traction energy` | Валовая энергия, использованная мотором для движения | кВт·ч |
| `regen energy` | Энергия, возвращённая рекуперативным торможением | кВт·ч |
| `net driving energy` | `traction energy − regen energy` | кВт·ч |
| `consumption` | Энергия, израсходованная на 100 км | кВт·ч/100 км |
| `predicted consumption` | Прогноз расхода, объединяющий текущие и исторические сигналы | кВт·ч/100 км |
| `percent/second` | Расчётная скорость зарядки: `(P / C × 100) / 3600` | Процентные пункты/с |
| `elapsed seconds` | Секунды по часам с начала сессии | Секунды |
| `active seconds` | Использованные в оценке секунды зарядки, ограниченные расчётным временем завершения | Секунды |
| `weight` | Относительное влияние одного входного значения в смешанном прогнозе | Без единицы |
| `environment factor` | Ограниченный множитель влияния температуры, скорости, климатической установки и давления в шинах | Безразмерный множитель |
| `clamp(value, min, max)` | Ограничивает значение снизу `min` и сверху `max` | Та же единица, что у значения |
| `Σ` | Сумма всех подходящих значений | Зависит от значений |

### Смысл основных терминов

| Термин | Простое объяснение | Пример |
| --- | --- | --- |
| Ёмкость батареи | Энергия, которую батарея может хранить при полном заряде. Это настроенная полезная ёмкость автомобиля, а не текущая энергия. | При батарее 45,1 кВт·ч и SOC 50% внутри примерно 22,6 кВт·ч до поправки на SOH. |
| Энергия на стороне батареи | Энергия, которая фактически достигает ячеек или выходит из них. При зарядке она меньше энергии из сети из-за потерь и работы охлаждения, нагрева и электроники. | Если в батарею попало 18 кВт·ч при эффективности 90%, зарядное устройство отдаст около 20 кВт·ч. |
| Энергия со стороны сети | Энергия, взятая из розетки или у оператора зарядки. Именно она важна для счёта за электричество. | `18 battery kWh / 0.90 efficiency = 20 grid kWh`. |
| Энергия, нужная батарее | Энергия на стороне батареи для перехода от текущего SOC к целевому. | Батарее 45 кВт·ч при переходе с 40% на 80% нужно `45 × 40% = 18 battery kWh`. |
| Оставшаяся энергия сети | Оценка энергии, которую зарядное устройство ещё возьмёт до выбранного SOC. Она включает потери и обычно больше оставшейся энергии батареи. | При переходе с 40% на 80% у батареи 45 кВт·ч и эффективности 90%: `18 / 0.90 = 20 grid kWh remaining`. |
| Полученная энергия сети | Оценка энергии, уже переданной зарядным устройством в текущей сессии. Она используется для оценки стоимости. | Прирост SOC на 20 процентных пунктов у батареи 45 кВт·ч при эффективности 90% даёт `45 × 20% / 0.90 = 10 grid kWh`. |
| Эффективность зарядки | Доля энергии зарядного устройства, которая становится энергией батареи. VoltFlow использует значения для конкретного тарифа, поскольку потери AC и fast DC различаются. | При эффективности 90% из 10 сетевых кВт·ч в батарее сохраняется около 9 кВт·ч. |
| Мощность зарядки | Скорость передачи энергии в данный момент или в среднем. Мощность измеряется в кВт, накопленная энергия — в кВт·ч. | Стабильное зарядное устройство на 7 кВт передаёт около 7 кВт·ч за час. |
| Тяговая энергия | Энергия движения до вычитания энергии, позже возвращённой рекуперацией. | На поездке тяга может потратить 5 кВт·ч, а рекуперация вернуть 0,7 кВт·ч. |
| Рекуперированная энергия | Энергия, возвращённая в батарею при замедлении мотором. | При 5 кВт·ч тяги и 0,7 кВт·ч рекуперации чистый расход батареи около 4,3 кВт·ч. |
| Чистый расход | Расход движения после вычитания рекуперации. | `(5 − 0.7) / 25 km × 100 = 17.2 kWh/100 km`. |
| Валовая энергия движения | Общая тяговая энергия до вычитания рекуперации. История использует её в балансе заряженной и израсходованной энергии. | В примере выше валовая энергия движения — 5 кВт·ч. |
| Прирост/падение SOC | Разница двух процентов батареи в процентных пунктах, а не относительное изменение в процентах. | Переход с 40% на 60% — прирост SOC на 20 пунктов. |
| Среднее с учётом расстояния | Среднее, в котором длинные поездки влияют сильнее коротких. | Поездка на 100 км влияет в десять раз сильнее поездки на 10 км. |
| Медиана | Среднее по позиции после сортировки наблюдений; меньше зависит от одного необычного значения. | Для `14, 15, 30` медиана равна 15. |
| Оценка или fallback | Расчётная замена, используемая при отсутствии предпочтительного измерения. Это не прямое измерение автомобиля. | Прогресс по времени — fallback, когда live-SOC устарел. |
| Прогноз | Проекция, намеренно объединяющая несколько сигналов и допущений. Она может отличаться от сырого значения автомобиля и простого исторического среднего. | AI-запас хода объединяет расход, live-мощность/скорость, погоду и SOH. |

### Пример расчёта зарядки

Пусть батарея 45 кВт·ч заряжена до 40%, цель — 80%, эффективность — 90%, мощность
зарядки — 7 кВт, а электричество стоит 0,50 за кВт·ч:

1. Требуемый прирост SOC: `80% − 40% = 40 процентных пунктов`.
2. Энергия на стороне батареи: `45 × 40 / 100 = 18 кВт·ч`.
3. **Оставшаяся энергия сети:** `18 / 0.90 = 20 кВт·ч`. Это энергия, которую зарядное
   устройство, как ожидается, возьмёт, чтобы передать батарее 18 кВт·ч.
4. Расчётное время: `20 / 7 = 2.86 часа`, то есть примерно 2 ч 51 мин.
5. Расчётная стоимость: `20 × 0.50 = 10.00` в выбранной валюте.

## Dashboard (`/dashboard`)

| Элемент Dashboard | Формула или правило | Объяснение |
| --- | --- | --- |
| Доступная энергия батареи | `C × clamp(SOC, 0, 100) / 100` | Преобразует текущий процент батареи в доступные кВт·ч. |
| Отображение батареи | `available kWh / C` | Показывает доступную энергию рядом с полной ёмкостью батареи. |
| Расчётный запас хода | `usable energy / predicted consumption × 100` | Прогнозирует расстояние по доступной энергии и смешанному расходу. |
| Ёмкость с поправкой на SOH | `C × clamp(SOH, 70, 105) / 100` | Корректирует полезную ёмкость по измеренному состоянию батареи. |
| Прогнозируемый расход | `Σ(estimate × weight) / Σweight` | Объединяет текущую поездку, недавние поездки, энергию, мгновенную мощность, запас хода автомобиля и историю. |
| Вход мгновенного расхода | `power kW / speed km/h × 100` | Преобразует live-тяговую мощность и скорость в кВт·ч/100 км при подходящей скорости. |
| Расход из запаса хода автомобиля | `(usable battery × SOC/100) / reported range × 100` | Получает расход, подразумеваемый собственным запасом хода автомобиля. |
| Поправка на окружающую среду | `predicted consumption × environment factor` | Применяет ограниченные штрафы за температуру, высокую скорость, климатическую установку и низкое давление в шинах. |
| Энергия до 100% | `C × (100 − SOC) / 100 / (η/100)` | Оценивает сетевую энергию для полного заряда. |
| Расчётная стоимость зарядки | `required grid energy × p` | Оценивает стоимость сетевой энергии. |
| Время AC до 100% | `required grid energy / P` | Предполагает постоянную мощность AC-зарядки. |
| Время DC до 100% | Сумма времени по диапазонам SOC | Использует выбранную мощность до 70%, затем ограничивает её 45 кВт до 90%, 25 кВт до 95% и 15 кВт до 100%. |
| Оставшийся SOC активной зарядки | `max(0, target SOC − current SOC)` | Процентные пункты, оставшиеся до цели. |
| Оставшееся время активной зарядки | `remaining grid energy to 100% / P_grid` | Dashboard показывает время до 100%; `P_grid` — разрешённая мощность активной сессии, включая правило зрелого AC-наблюдаемого среднего ниже. |
| Разрешённая мощность активной зарядки | `resolveChargingEtaPowerKw(live P, observed session energy/time, fallback)` | Сначала используется свежая live-мощность; после 15 минут и 2 пунктов SOC зрелое целочисленное AC-значение может использовать наблюдаемое среднее при совпадении целой корзины. Для DC и уже дробного live-значения сохраняется live; иначе используется fallback сессии/автомобиля/по умолчанию. |
| Длительность последней зарядки | `stop time − start time` | Прошедшее время последней сессии зарядки. |
| Пара SOC последней поездки | `start SOC → end SOC` | Отображаемые сохранённые значения поездки, не производный результат энергии. |

## Детали активной сессии зарядки

SOC, энергия и стоимость используют канонический приоритет: свежий live-SOC (до 90 секунд),
затем телеметрия сессии, затем расчёт по часам. Оценка времени не должна подменять свежие
данные автомобиля.

| Отображаемый результат | Формула или правило | Объяснение |
| --- | --- | --- |
| Текущий SOC | Свежий live-SOC, затем телеметрия, затем оценка по времени | Выбирает наиболее надёжный источник. |
| Полученная энергия | `C × (current SOC − start SOC) / 100 / (η/100)` | Преобразует измеренный прирост SOC в сетевую энергию. |
| Текущая стоимость зарядки | `charged grid energy × p` | Текущая расчётная стоимость сессии. |
| Прошедшее время | `now − start time` | Время с начала сессии. |
| Оставшаяся энергия сети | `C × (target SOC − current SOC) / 100 / (η/100)` | Энергия, которую зарядное устройство ожидаемо возьмёт от текущего SOC до цели с учётом потерь. Это не энергия, уже находящаяся в батарее. |
| Оставшееся время | `remaining grid energy / P_grid` | Dashboard, `/vehicle`, детали активной сессии и Telegram live widget используют одну разрешённую отображаемую мощность. В проекциях деталей сессии она преобразуется в `P_batt = P_grid × η/100`; это алгебраически эквивалентно делению сетевой энергии на сетевую мощность. Telegram читает активные сессии одним запросом с ограничением по пользователю после существующего throttle и возвращается к сырой/стандартной мощности при отсутствии контекста сессии. |
| Проекции SOC вперёд | `start SOC + (P_batt / C × 100) × elapsed seconds / 3600` | Детали активной сессии используют разрешённую мощность и эффективность для обратного отсчёта до цели, расчётного окончания и проекции SOC на ближайшие 07:00. |
| Fallback SOC по времени | `start SOC + percent/second × elapsed seconds` | Оценивает SOC без пригодных live-данных. |
| Fallback энергии по времени | `P × active seconds / 3600` | Оценивает энергию по настроенной мощности и времени. |
| Fallback стоимости по времени | `p × P × active seconds / 3600` | Оценивает стоимость по времени, мощности и цене. |
| Оставшееся время по часам | `(target SOC − current SOC) / percent/second` | Оценивает оставшееся время при настроенной скорости. |
| Защитный потолок SOC | `min(target SOC, latest real SOC + rate × seconds since reading)` | Не даёт прогрессу по времени сильно опередить последнее реальное значение SOC. |
| Завершение | `current SOC ≥ target SOC` плюс проверки live-данных | Не даёт сохранить завершение только по математике поверх свежих данных автомобиля. |
| Отображаемая мощность зарядки | Учитывающая квантизацию AC оценка, затем live `charge_power_kw`, затем fallback сессии/автомобиля/по умолчанию | В зрелой AC-сессии (не менее 15 минут и 2 пунктов SOC) целочисленное live-значение может использовать полное наблюдаемое среднее при совпадении целой корзины (`1` и наблюдаемое `1.4` отображаются как `~1.4 kW`). Для DC, уже дробных live-значений и несовпадающих корзин сохраняется live. Та же `P_grid` используется для ETA и прямых проекций. |

Источники-владельцы: [`charging-live.ts`](../src/features/charging/_domain/charging-live.ts),
[`charging-math.ts`](../src/features/charging/_domain/charging-math.ts),
[`dashboard-view.tsx`](../src/components/dashboard/dashboard-view.tsx),
[`vehicle-live-view.tsx`](../src/components/vehicle/vehicle-live-view.tsx) и
[`charging-session-screen.tsx`](../src/features/charging/_ui/charging-session-screen.tsx),
а для Telegram — [`live-widget-charging.ts`](../src/lib/telegram/live-widget-charging.ts).

> Счётчик BMS `kwh_charged` используется для диагностики. Основные энергия, стоимость и
> отображение мощности зарядки его не используют, поскольку он отражает сторону ячеек и
> не учитывает вспомогательную нагрузку.

## Исправление завершённой сессии

| Отображаемый результат | Формула | Объяснение |
| --- | --- | --- |
| Скорректированная цена за кВт·ч | `total paid / billed kWh` | Эффективная цена оператора по чеку. |
| Измеренная эффективность зарядки | `((SOC gain/100) × C / billed kWh) × 100` | Сравнивает энергию, сохранённую в батарее, с энергией сети по чеку. |
| Средняя мощность зарядки | `Σpositive charge_power_kw / count(positive charge_power_kw)` | Использует только значения положительной `charge_power_kw` из окна зарядки; счётчик BMS `kwh_charged` не используется. |
| Средняя температура батареи | `Σbattery temperature / valid sample count` | Температурный контекст сессии зарядки. |
| Средняя температура снаружи | `Σoutside temperature / valid sample count` | Контекст температуры окружающей среды. |

Источники-владельцы: [`energy-correction-card.tsx`](../src/features/charging/_ui/energy-correction-card.tsx)
и [`charging-efficiency-learning.ts`](../src/lib/charging-efficiency-learning.ts).

## Форма ручной сессии зарядки

| Результат предпросмотра | Формула | Объяснение |
| --- | --- | --- |
| Длительность | `(stop time − start time) / 3,600,000` | Переводит введённый период в часы. |
| Средняя мощность зарядки | `billed kWh / duration hours`, ограничение 350 кВт | Восстанавливает среднюю мощность по данным чека. |

| Целевой SOC | `start SOC + estimated SOC gain`, ограничение 100% | По возможности привязывает восстановленный прирост к ближайшей телеметрии. |

## Правило сопровождения

При изменении пользовательской формулы обновляйте этот справочник в той же утверждённой
задаче, что и исходную реализацию и канонический документ предметной области. Сохраняйте
различие между:

- сырыми значениями, сообщёнными автомобилем;
- точными итогами, выведенными из сохранённых фактов;
- оценками и fallback-значениями;
- прогнозами, намеренно объединяющими несколько сигналов.
