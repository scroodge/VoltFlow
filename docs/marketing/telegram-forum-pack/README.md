Для ручной публикации пользователем в https://t.me/voltflowfaq. Ничего не опубликовано.

## Перед публикацией

- Не повторять вступления тем и уже закреплённое «⚡ Добро пожаловать…»: черновик 01 исключён.
- Публиковать в указанную тему, сверху вниз. Ниже дан точный текст каждого TXT.
- Для постов с изображениями: прикрепить файлы в указанном порядке одним альбомом, текст вставить в подпись к первому изображению. Если указано «send images first, then text», отправить альбом без подписи и затем текст отдельным сообщением.
- FAQ и шаблоны отправлять как обычные текстовые сообщения.
- Данные на скриншотах вымышленные; изображения взяты только из манифеста захвата 7 октября 2026. Подписи демо сохранены.
- Проверка подписи: предел 1024; дополнительно подсчитаны UTF-16 единицы, чтобы учитывать emoji. Текстовые сообщения проверены против 4096.
- Проверить открытые вопросы ниже; фактическая работа production и внешних интеграций здесь не проверялась.

❓ Как считается стоимость зарядки?

Оценка энергии в батарее = ёмкость × прирост SOC / 100. Энергия из сети = энергия в батарее / (эффективность / 100). Стоимость = энергия из сети × ваш тариф за кВт·ч. ## Примечания к изображениям

В истории зарядок есть известная метка Custom вместо имени провайдера; подпись не утверждает, что метка верна. Активные экраны имеют разные цели оценки времени. Калькулятор — самостоятельный пример с другими настройками. GPS-маршруты, реальные подключения и отправка команд данным набором не подтверждены.
